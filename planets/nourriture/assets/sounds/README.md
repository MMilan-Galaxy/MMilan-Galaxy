# Pistes audio Saccharia

Sans fichiers, le jeu utilise **sons synthétisés**, **musique procédurale** et **voix navigateur** (fr-FR).

Pour des pistes plus immersives, ajoutez des MP3 avec ces noms exacts :

## Musique de fond (boucle)
| Fichier | Quand |
|---------|--------|
| `bgm_world.mp3` | Monde principal (pastel) |
| `bgm_kitchen.mp3` | Cuisine / mélange du soufflé |
| `bgm_throne.mp3` | Salle du trône |
| `bgm_west.mp3` | Sweet Island (ouest) |
| `bgm_east.mp3` | Cuisine salée (est) |
| `bgm_angry.mp3` | Zone amère / survie |

## Boucles d'action
| Fichier | Quand |
|---------|--------|
| `loop_mix.mp3` | Mélange soupe (roi) ou pâte (four ouest) |
| `loop_oven.mp3` | Cuisson au four géant |
| `loop_pour.mp3` | Versement dans le bol |

## Effets courts
| Fichier | Quand |
|---------|--------|
| `pickup.mp3` | Ramasser un objet |
| `lose.mp3` | Défaite mini-jeu |
| `win.mp3` | Victoire |
| `king_angry.mp3` | Roi en colère |
| `hurt.mp3` | Choc épreuve Baron |
| `wrong.mp3` | Mauvaise réponse (est) |
| `interact.mp3` | Touche E / interaction |
| `blow.mp3` | Souffle sur buissons |
| `mix_start.mp3` | Début mélange soufflé |
| `memory_beep.mp3` | Bouton distributeur (mémoire) |
| `bake_done.mp3` | Gâteau cuit |

## Voix dialogues

Fichiers MP3 dans `voices/` (un extrait humain par personnage). Voir `voices/README.md`.
Pas de synthèse vocale navigateur.

Sources libres : [Mixkit](https://mixkit.co/), [Freesound](https://freesound.org/), [OpenGameArt](https://opengameart.org/).

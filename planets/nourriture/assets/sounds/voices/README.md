# Voix des personnages (MP3 humains, libres de droit)

Le jeu **n'utilise plus** la synthèse vocale du navigateur (trop « IA »).

À chaque dialogue, un **fichier court** est joué selon le personnage. Le texte reste affiché à l'écran ; l'audio est une réplique type (murmure, exclamation, etc.).

## Fichiers à ajouter

| Fichier | Personnage |
|---------|------------|
| `roi.mp3` | Roi Dulcis |
| `confiturio.mp3` | Confiturio |
| `chef_marshmallow.mp3` | Chef Marshmallow |
| `chef_sali.mp3` | Chef Sali |
| `baron.mp3` | Baron |
| `zyx.mp3` | Zyx |
| `narrateur.mp3` | Narrateur |
| `distributeur.mp3` | Distributeur / Four |
| `systeme.mp3` | Messages système |
| `default.mp3` | Autres PNJ (obligatoire en secours) |

Durée conseillée : **0,5 à 2,5 secondes** par fichier.

## Où trouver des voix libres de droit

- [Pixabay — Voice](https://pixabay.com/sound-effects/search/voice/) (licence Pixabay)
- [Mixkit — Voice](https://mixkit.co/free-sound-effects/voice/) (gratuit)
- [Freesound](https://freesound.org/) (vérifier licence CC0 / attribution)
- [OpenGameArt](https://opengameart.org/) (filtre « voice »)

Choisis des extraits **naturels** (pas de TTS). Renomme-les comme dans le tableau ci-dessus.
